# LeoMart

A responsive, Walmart-inspired e-commerce frontend built with plain HTML, CSS and JavaScript.

## Features
- Responsive homepage
- Search
- Category filtering
- Sorting
- Product detail pages
- Shopping cart with quantity controls
- LocalStorage persistence
- Demo checkout
- GitHub Pages compatible
- No backend required

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload all files to a GitHub repository, then go to **Settings → Pages** and select the branch containing `index.html` as the deployment source.
